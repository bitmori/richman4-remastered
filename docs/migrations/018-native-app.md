# 018 — Mac ARM64 原生应用与无桌面操作回放

`tools/native_game.cpp` 是独立的 SDL3 应用，直接链接可移植 C++ 核心，读取原 MKF/地图/音频资源。原生运行时不启动 Wine、不加载原 EXE、不调用 x86 汇编。

## 应用边界

画布保持 640×480，窗口按最近邻缩放并保留黑边。地图、人物、建筑、菜单、肖像使用原素材；交互由 SDL 鼠标/键盘事件驱动。逻辑状态由 `GameSession` 管理，绘图、声音与按钮不直接修改资金、随机数、产权或回合。

提供新开局、角色与八张地图选择、四人回合、存读档、相机旋转、财富信息、卡片、道具、股票交易、速度、音乐/音效开关和全屏。交易数量支持点击输入、增减和全部；卡片的被动防御标为自动。银行、商店、魔法、设施和事件共享可分页的选择界面；模态选择遮挡后方按钮，防止点穿。

字体读取本机细明体，缺失时使用系统苹方或显式 `--font`。原资源/存档的 Big5 字节保留，仅显示时转成 UTF-8。FreeType 的黑白栅格化会丢掉本机细明体的小号细笔画，因此使用灰度覆盖率在 RGB555 画布上混合，地图仍按最近邻呈现。没有修改原字体文件。

保存目录默认 `~/Library/Application Support/Rich4Native/saves`。`Save1.DAT` 可由原格式解析器回读，`.rng` 保存原生确定性随机流状态；`Autosave.DAT` 在可保存的人类回合写入，也保留随机状态。导入原存档只读；所有回放保存到独立证据目录。

## 不占桌面的验证

```sh
python3 scripts/run_native_playability.py --turns 30 --seed 42
# 读入外部原始存档（仍只写回放私有目录）
python3 scripts/run_native_playability.py --load /path/to/SAVE1.DAT --turns 30
```

`--headless` 在初始化前强制 SDL video/audio 的 `dummy` 驱动，不使用 Mac 桌面自动化。测试把按钮中心从逻辑画布转换为真实窗口坐标，通过 `SDL_PushEvent` 发送鼠标按下/抬起，再由正常输入路径转换回逻辑坐标。它不直接调用游戏移动函数完成回合。

回放依次执行菜单→开局/读档→卡片/道具/股票操作→人类掷骰→AI 行动→事件选择→存档→同一界面读回。记录前后 DAT/PPM、逐事件 JSONL、操作和声音推进数量，以及存读档逐字节、随机数状态比较。外围 Python 另检查进程退出、证据存在、原文件 SHA-256 不变和报告完整性。

门槛拒绝 Wine 回退、非 dummy 设备、没有实际 SDL 操作/移动、未完成天数（已正常结局除外）、存读档不一致、任何 unsupported 事件。单元测试还故意删去证据字段和加入跳过事件，确认这些情况不能得到 passed。

## 当前证据与边界

2026-10-05 第一轮三天真实原生回放已通过：12 次掷骰、43 次移动、10 次土地/设施购买、实际存读档字节一致、92,160 帧混音、一次角色语音。证据在本机 `artifacts/native-playability/20261005-135832-1e6c02cf`。

随后三十天回放完成 111 次掷骰、391 次移动、43 次购买、4 次升级、24 次租金支付，但仍因商业设施、区域效果、彩票和 AI 贷款缺失而判 failed。该结果用于继续修复，不能作为完整可玩性声明。每次规则变化后需重新运行最新程序；旧报告不代表新提交的覆盖率。

逐个模块的原版金标验证与完整游戏回放是不同证据。当前原生界面没有宣称全部规则、原版 AI、所有历史快照、逐帧动画或整局随机轨迹完全等价。原版会用宿主时钟多次重播种，计时器动画也会取随机数；原生可重放流程的处理须在对应规则记录中明确。

最新接入主动操作后的三十天回放（`20261005-142416-d9230d09`）完成 116 次骰子、406 步、46 次购买、6 次升级、22 次租金与 5 次道具；DAT 和 PRNG 恢复一致。前轮四类规则缺口已消除，本轮仍因机器娃娃动作 callback 未接而 failed；继续修复中。该正常新局没有主动卡片消费，也没有成功股票往返，不把这些按钮点击当作效果验证。

`--hidden-window` 供 macOS 平台冒烟检查：保持真实 Cocoa/Metal 驱动但不显示窗口，并设置 SDL_MAC_BACKGROUND_APP 避免激活前台。它与 `--headless` 的 dummy 验证分开记录，不能混用报告。

2026-10-05 `20261005-143025-223e8779`：含主动操作的30天原生回放通过，106骰/403步、40购买/2升级/21租金，3张卡/6件道具，股票买卖各1次，DAT与PRNG恢复一致，unsupported为空。真正 Cocoa + Metal 的隐藏窗口3天检查也通过（`artifacts/native-platform-smoke/20261005-143100`）；该检查音频仍使用dummy，不声称音频设备的听感验证。机器娃娃缺口已在后续core补上；其它地图、复杂状态和完整结局继续扩大覆盖。
