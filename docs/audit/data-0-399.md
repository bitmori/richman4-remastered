## Ranked B gaps

1. **Festival calendar picture (Data 4–127).** It is on screen all day on every holiday, on both the main-screen calendar and the bank screen.
   Hint: add `holidays::festival_row(date,map,stage)` mirroring `fcn_004521f0`. When it returns a row, blit raw RGB555 200×200 `Data[{4,28,47,67,87,108,95,118}[stage*4+map] + row]` at (440,280) instead of `P2:season`. Use the same code in finance.cpp:478.
2. **Construction-vehicle demolish animation (pose 12 + Data 526 + sound).** It happens each time a 工程車 stops on an opponent's building, and today it is only a text notice.
   Hint: emit an effect from `flight_bombardment()`. It should turn the actor toward the building, cycle `0x80+c*21+12` frames, play the sound at frame 2, demolish at frame 3, and show `EffectKind::demon_puff`-style Data 526 at the building anchor −(55,55). Also rename the function and notice from "flight" to 工程車.
3. **Early-release gown/stripes sprites (poses 19/20).** Rare (prison↔hospital transfer, UFO) and short-lived.
   Hint: add `PlayerSprite::released_from` (hospital → 19, prison → 20) to `player_resource`, set it when `fcn_0040d761`'s equivalent clears a confinement, and clear it on the next normal sprite update.
